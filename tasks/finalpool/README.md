# Final Pool

Implemented tasks collected from the developer branches of BenchTasksCollv3. Each directory contains a completed task satisfying the requirements under `tasks/examples/example-task`: non-empty English `docs/task.md` and `docs/agent_system_prompt.md`, plus optional evaluation/preprocessing/groundwork files.

Statuses for every task are tracked in the Notion Task Tracker (`Task Status Table`): `implemented` tasks live in this folder; `implementing` tasks remain on their developer branches.
